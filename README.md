Investigador en ciencia de materiales y desarrollo de conglomerantes sostenibles por activación alcalina. En paralelo al laboratorio, diseño herramientas ligeras para automatizar flujos de trabajo científicos, análisis de datos y utilidades cotidianas sin depender de infraestructuras pesadas.

* 🔬 **Laboratorio:** Economía circular, valorización de subproductos industriales, geopolímeros y caracterización fisicoquímica.
* ⚡ **Código:** Scripts deterministas, interfaces limpias en un solo archivo y automatización local asistida por IA.
* 🛠️ **Enfoque:** Si un problema se resuelve con un `.py` autocontenido o un `index.html` sin build steps, no hace falta levantar un servidor.

### `design_principles`

```text
├── Single-File WebApps   → HTML + JS + CSS autocontenidos (BYOK, Offline-first, Dark Mode)
├── Local Python Tools    → Arquitectura portable (main.py + config.json + ejecutar.bat)
├── Scientific Workflow   → Procesamiento de datos experimentales, parsing y LaTeX
└── Pragmatism            → Cero bloatware; prioridad absoluta a la trazabilidad y velocidad
